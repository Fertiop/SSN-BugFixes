# SSN-BugFixes

Независимый мод-фикс для **Simple Storage Network (SSN)**. Цель — исправлять подтверждённые ошибки самого SSN, **не** изменяя оригинальный JAR, исходники Factotum или поведение других модов.

## Целевая среда

- Minecraft **1.20.1**
- Minecraft Forge **47.x**
- Simple Storage Network **1.13.2**
- FLib — совместимая версия, требуемая установленным SSN
- Java **17**

Исходная база для анализа: [Lothrazar/Storage-Network, ветка `trunk/1.20.1`](https://github.com/Lothrazar/Storage-Network/tree/trunk/1.20.1).

## Текущий статус

**В отдельной ветке подготовлены два непроверенных Mixin-патча** (`SSN-001` и `SSN-002`): [fix/ssn-001-002-source-patches](https://github.com/Fertiop/SSN-BugFixes/tree/fix/ssn-001-002-source-patches). Они ещё не собраны и не запущены в игре, поэтому **нет проверенного исправления или релизного JAR**. `main` остаётся стабильной исходной веткой без активных патчей.

## Принципы

1. Каждый фикс относится к дефекту **самого SSN**, а не к интеграции Factotum ↔ SSN.
2. Сначала доказать первопричину и воспроизвести проблему; потом менять поведение.
3. Не допускать потери или дублирования предметов. Проверять инвариант количества до и после операции.
4. Минимизировать вмешательство в SSN. Предпочитать точечные исправления с проверкой версии и возможностью отключения.
5. Не заявлять о работающем релизе без сборки и тестирования.

## Сборка (для разработчиков)

Необходима локально установленная **JDK 17**. Из корня проекта, **после разрешения владельца на сборку**, выполните:

```bash
./gradlew build
```

На Windows: `gradlew.bat build`. Готовый JAR появится в `build/libs`, если сборка пройдёт успешно. Wrapper версии **8.8** взят из официального репозитория `gradle/gradle`, тег `v8.8.0`. Сборка и игровой запуск **ещё не проверены**.

Для проверки в клиенте и на сервере также нужны оригинальные **SSN 1.13.2** и совместимая **FLib**; эти сторонние JAR в репозиторий не добавляются. Стартовый мод не меняет поведение SSN — **его не следует распространять как исправление**.

## Установка

Пока устанавливать как фикс нечего: выходной `.jar` с исправлениями ещё не собран и не проверен. После появления проверенного релиза он будет устанавливаться **в дополнение к SSN** в папку `mods` клиента и сервера (если патчи затрагивают серверную логику).

## Происхождение и лицензия

SSN — сторонний проект его авторов. Этот репозиторий не является официальным исправлением SSN. Лицензия нашего кода пока **не выбрана**; до её добавления не предполагается каких-либо дополнительных разрешений на распространение.
