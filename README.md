# SSN-BugFixes

Независимый Forge companion-мод с точечными исправлениями **Simple Storage Network (SSN) 1.13.2** на **Minecraft 1.20.1**, Forge 47.x, Java 17. Исходный SSN и Factotum не изменяются и не перепаковываются.

## Состояние разработки — 2026-10-26

**Все семь найденных дефектов имеют патчи и игровые RED/GREEN-проверки.** Первоначальный реестр содержал SSN-001–006; отдельным SSN-007 выделена обнаруженная при исправлении пульта ошибка возврата *симулированного* предмета из API сети.

| ID | Исправление |
|---|---|
| SSN-001 | Сохранение унаследованной NBT-связи терминала с сетью |
| SSN-002 | Защита подсказки строительного пульта при `Level == null` |
| SSN-003 | Приоритет двух кабелей до дедупликации одного сундука |
| SSN-004 | Реальное списание материала до размещения блока; возврат игроку при неудаче |
| SSN-005 | Сохранение неиспользованных ингредиентов при массовом крафте со сдачей тары |
| SSN-006 | Ошибка одного провайдера больше не обрывает чтение следующих хранилищ |
| SSN-007 | Не возвращать виртуальный результат симуляции, если реальное извлечение не состоялось |

**Проверенные результаты:** 20 Forge GameTests на реальном SSN с патчами без отказов, 10 конкретных RED-сценариев на оригинальном SSN, шесть проверок байткода релизного SSN, успешная Forge-сборка и проверка Mixin/JAR. [Последний проверенный GREEN/RED](https://github.com/Fertiop/SSN-BugFixes/actions/runs/40387833982). Отдельный последующий CI-коммит сделал ранее экспериментальные проверки обязательными.

**Это ещё не готовый релиз:** необходимы полноценный перезапуск сохранённого мира, клиентская проверка tooltip/GUI и испытание на модпаке. Не устанавливайте экспериментальный JAR в основной мир без резервной копии.

## Сборка разработчика

Нужна JDK 17; ForgeGradle скачает указанные зависимости, включая SSN 1.13.2 и FLib 0.0.16. В корне проекта:

```bash
./gradlew build
./gradlew runGameTestServer
```

На Windows используйте `gradlew.bat`. Для сравнения с оригинальным SSN *без наших Mixin*:

```bash
./gradlew -PssnBaseline runGameTestServer
```

RED-режим **преднамеренно завершается ошибками** — это проверка, что тесты ловят именно исходные дефекты.
