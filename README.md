# SSN-BugFixes

Независимый мод-фикс для **Simple Storage Network (SSN)**. Цель — исправлять подтверждённые ошибки самого SSN, **не** изменяя оригинальный JAR, исходники Factotum или поведение других модов.

## Целевая среда

- Minecraft **1.20.1**
- Minecraft Forge **47.x**
- Simple Storage Network **1.13.2**
- FLib — совместимая версия, требуемая установленным SSN
- Java **17**

Исходная база для анализа: [Lothrazar/Storage-Network, ветка `trunk/1.20.1`](https://github.com/Lothrazar/Storage-Network/tree/trunk/1.20.1).

## Текущий статус

**Подготовка репозитория / исследование.** В этом репозитории пока **нет готовых Java-патчей и релизного JAR**. Записи в реестре не означают, что дефекты воспроизведены в Minecraft или исправлены.

- [Границы проекта и правила совместимости](docs/SCOPE.md)

## Принципы

1. Каждый фикс относится к дефекту **самого SSN**, а не к интеграции Factotum ↔ SSN.
2. Сначала доказать первопричину и воспроизвести проблему; потом менять поведение.
3. Не допускать потери или дублирования предметов. Проверять инвариант количества до и после операции.
4. Минимизировать вмешательство в SSN. Предпочитать точечные исправления с проверкой версии и возможностью отключения.
5. Не заявлять о работающем релизе без сборки и тестирования.

## Установка

Пока установить нечего: выходной `.jar` ещё не собран. После появления проверенного релиза он будет устанавливаться **в дополнение к SSN** в папку `mods` клиента и сервера (если патчи затрагивают серверную логику).

## Происхождение и лицензия

SSN — сторонний проект его авторов. Этот репозиторий не является официальным исправлением SSN. Лицензия нашего кода пока **не выбрана**; до её добавления не предполагается каких-либо дополнительных разрешений на распространение.
