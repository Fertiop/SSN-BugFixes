# SSN-BugFixes

Независимый Forge-мод с точечными исправлениями **Simple Storage Network 1.13.2** для **Minecraft 1.20.1**, Java 17 и Forge 47.x. Исходный SSN и Factotum не модифицируются и не перепаковываются.

## Текущий статус

**Экспериментальная ветка:** [`fix/ssn-001-002-source-patches`](https://github.com/Fertiop/SSN-BugFixes/tree/fix/ssn-001-002-source-patches). [Draft PR #1](https://github.com/Fertiop/SSN-BugFixes/pull/1).

- **SSN-001:** Mixin исправляет сохранение унаследованного NBT терминала. Сохранение/загрузка в GameTest проверены; перезапуск мира с диска не проверен.
- **SSN-002:** Mixin обрабатывает `Level == null` у строительного пульта. Проверки с/без NBT и с настоящим миром прошли; полноценную клиентскую подсказку ещё необходимо проверить.
- **SSN-003–006:** исправлений пока нет. В Minecraft воспроизведены: конфликт приоритетов двух кабелей на одном сундуке (интерпретация замысла ещё уточняется), бесплатная установка блока при расхождении simulate/execute, потеря четырёх неиспользованных бутылочек мёда при массовом крафте и пропуск исправного хранилища при исключении другого.

## Результаты тестов

- **6/6 проверок исходного JAR** SSN 1.13.2: прошли (не подтверждают качество патча).
- **18 Forge GameTests:** 14 обязательных прошли, 4 исследовательских выдали ожидаемые сообщения о дефектах. [Лог запуска](https://github.com/Fertiop/SSN-BugFixes/actions/runs/40380365809).
- **Проверка RED на исходном SSN:** четыре ожидаемых теста SSN-001/002 действительно провалились; с патчами те же тесты проходят. Первоначальный анализатор отчёта не распознавал регистр имён и `failed!`; исправлен. [Контрольный запуск](https://github.com/Fertiop/SSN-BugFixes/actions/runs/40380161104), [протокол](docs/test_evidence/2026-10-26.md).
- **Сборка Forge и проверка содержимого JAR:** прошли в CI. Искусственно неисправные хранилища, Java GameTests и `empty.nbt` исключены из игрового JAR.

**Готового проверенного релиза нет.** Пакет ещё не испытан на реальном клиентском GUI, долговременном сохранении/открытии мира и типичном модпаке. Не устанавливайте CI-сборку в основной мир без резервной копии.

## Сборка разработчика

Нужны JDK 17, оригинальные SSN 1.13.2 и совместимая FLib. Из корня проекта:

```bash
./gradlew build
./gradlew runGameTestServer
```

На Windows используйте `gradlew.bat`. RED-режим без наших Mixin на одноразовом игровом сервере:

```bash
./gradlew -PssnBaseline runGameTestServer
```

RED-режим **должен завершиться с ошибками SSN-001/002** — это контроль, что тесты действительно ловят исходные дефекты, а не способ получить релиз.
