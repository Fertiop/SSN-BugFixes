# SSN-BugFixes — запуск и толкование тестов

**Целевая среда:** Minecraft 1.20.1, Forge 47.3.0, Java 17, SSN 1.13.2 (Modrinth `UmSTgKWE`), FLib 0.0.16 (`CDihtEoy`). SSN и FLib загружаются как внешние зависимости, но не помещаются внутрь выпускаемого мода.

## Уровень A: проверка исходного JAR

```sh
SSN_JAR=/path/to/SimpleStorageNetwork-1.20.1-1.13.2.jar python -m unittest discover -s tests/static -p 'test_*.py' -v
```

Шесть проверок исходной реализации по SHA-256. Не говорят, исправлены ли ошибки. В GitHub Actions скачиваемый бинарник проверяется на совпадение хеша.

## Уровень B: Forge GameTests с активными патчами (GREEN)

```sh
./gradlew --no-daemon build
./gradlew --no-daemon runGameTestServer
```

18 сценариев (14 обязательных и 4 исследовательских): терминал/сериализация, null Level, две ссылки на хранилище, полное/частичное перемещение, NBT-варианты, нормальное размещение и честное списание ресурсов, нормальный крафт мёда, а также условные сбои SSN-003/004/005/006.

Обязательные тесты должны пройти. Четыре необязательных теста `required=false` пока **должны сообщать о ещё не устранённых дефектах**; их провал не означает, что найденный дефект исправлен. В CI явно проверяется ненулевое обнаружение 18 тестов и вывод успешности обязательных проверок.

## Уровень C: оригинальный SSN без патчей (RED)

```sh
./gradlew --no-daemon -PssnBaseline runGameTestServer
```

`ssnBaseline` отключает регистрацию нашей Mixin-конфигурации для тестового запуска. Должны провалиться четыре конкретных обязательных теста:

- `requestTerminalSavesInheritedConnection`
- `ssn_001_request_saves_connectable_and_ui_fields`
- `builderReturnsNullWithoutWorldEvenWithSavedState`
- `ssn_002_null_level_with_saved_blockstate`

При запуске Forge GameTest приводит camelCase к нижнему регистру и обозначает обязательные ошибки словом `failed!`. CI учитывает оба свойства формата. **Искусственно красный запуск — успешная проверка чувствительности тестов**, если нет посторонних обязательных отказов.

[Протокол запуска исходного RED](https://github.com/Fertiop/SSN-BugFixes/actions/runs/40380161104): все четыре ошибки наблюдались в самом Minecraft. Старый парсер вывел ложную ошибку проверки отчёта; исправлен. Повторная проверка нового парсера на архивном логе дала четыре ожидаемых имени и ноль неожиданных ошибок. Полностью зелёный новый job в GitHub Actions ещё нужно проверить.

## CI, упаковка и ограничения

- `.github/workflows/ssn-tests.yml`: исходный JAR, сборка, GREEN и RED на PR.
- `.github/workflows/gametest-manual.yml`: ручной запуск Minecraft-тестов.
- `build.gradle` исключает `gametest/**` и `data/ssnbugfixes/structures/empty.nbt` из итогового JAR. CI проверяет их отсутствие.

**Проверки вне автоматизированного набора:** закрытие/повторное открытие мира с сохранением диска, клиентские подсказки и UI, переподключение чанков, разные размеры инвентаря, реальные модпаки, сравнительные проверки vanilla-контейнера с рецептурными остатками. Всё это необходимо до выпуска релиза.

Детали каждого сценария и его ограничения — [TEST_MATRIX.md](TEST_MATRIX.md).
