## Инварианты ресурсов

Для перемещения: количество по ключу `item ID + NBT` в физических хранилищах, полученных стаках, инвентаре игрока и выброшенных ItemEntity должно совпадать до и после операции. Для крафта учитываются входные ингредиенты, продукт и `getRemainingItems`, иначе простая формула равенства штук некорректна.

## Оставшиеся пробелы

Отдельные CI теперь проверяют полное **сохранение → завершение процесса → перезапуск** Forge-сервера ([проверка 40391586565](https://github.com/Fertiop/SSN-BugFixes/actions/runs/40391586565)) и настоящий клиентский путь подсказки без игрока ([проверка 40391860401](https://github.com/Fertiop/SSN-BugFixes/actions/runs/40391860401)). Это не заменяет взаимодействие мышью с GUI, мультиплеерный клиент, выгрузку чанков и произвольные модпаки. Также не проверены все сторонние обработчики, фильтры и приоритеты в двойных сундуках, полные инвентари при возврате тары, модифицированные NBT-рецепты, принудительные аварии во время частичных передач. SSN-004 и SSN-006 используют намеренно неправильные сторонние провайдеры для проверки устойчивости, что не означает частого возникновения ситуации с обычным сундуком.

Точная первопричина каждого исправления и ссылки на файлы находятся в [BUG_REGISTRY.md](BUG_REGISTRY.md).
